## Jak pracować

1. Pobierz repozytorium i otwórz wybrany folder w edytorze.
2. Przygotuj środowisko zgodnie z README danej lekcji.
3. Wykonaj zadania, sprawdź wyniki i zapisz testy.
4. Oddaj aktualne źródła i dokumentację zgodnie z poleceniem.

Biblioteki i obrazy dla pierwszych ćwiczeń znajdują się w folderach lekcji 05-10. Projekty Node.js i Angular mogą wymagać instalacji zależności. Do pracy bez internetu korzystaj z przygotowanego przez nauczyciela środowiska.
